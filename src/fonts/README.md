# Outfit webfont

Outfit is self-hosted to match the typography used by the [Midnight overview page](https://midnight.network/overview). Visitors make no requests to a remote font service.

The unmodified variable WOFF2 files were supplied by Google Fonts, family Outfit, version 15, on 3 November 2026:

- Latin: `https://fonts.gstatic.com/s/outfit/v15/QGYvz_MVcBeNP4NJtEtq.woff2`
- Latin Extended: `https://fonts.gstatic.com/s/outfit/v15/QGYvz_MVcBeNP4NJuktqQ4E.woff2`
