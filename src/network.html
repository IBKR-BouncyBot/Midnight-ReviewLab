01 / YOUR WALLET

Start on Midnight Preview.

Use free test NIGHT, register it for DUST generation, and approve each transaction in your wallet.

1. Lace + Preview

Use Lace 2.5 or later and select the Midnight Preview network. Open this page in the browser where Lace is installed.

2. Test NIGHT → DUST

Fund your unshielded Preview address, then generate test DUST in Lace. DUST pays the network fee.

Open Preview faucet ↗
3. Prove in Lace

In Lace, open Settings → Midnight → On this device → Run in this app (WASM), then select Save configuration.

On-device proving and privacy

With Run in this app (WASM) selected, Lace generates contract and wallet/DUST proofs inside the wallet. Keep this setting enabled while connected. ReviewLab rejects a reported proof-server address and offers no fallback. The wallet connector cannot distinguish internal WASM from every other mode, including TEE, so you must check the setting in Lace yourself.
